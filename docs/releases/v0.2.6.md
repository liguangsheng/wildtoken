## 更新

- 新建渠道或快速导入时，保存同名渠道会用当前表单替换旧配置、Key 和分组。已归档的渠道会解除归档，沿用原 ID 和历史日志。要同时保留两套配置，请使用不同名称。
- 调试页可先选模型再发送请求，也可指定渠道对比回复。多轮会话和草稿保存在本机。
- 日志可识别 Zcode 和 Qoder 客户端。新请求的详情分别显示客户端发来的请求头和渠道实际转发的请求头。回到日志页时会重新连接并补齐遗漏的记录。
- 移除 Sakura Mist、Anthropic 和 Anthropic Dark 主题。原先选用这些主题的浏览器会自动切换到深色主题。

使用 Go 1.25 或更新版本可安装 CLI 和共享 skill。

```sh
go install github.com/liguangsheng/wildtoken/cmd/wildtokenctl@v0.2.6
wildtokenctl skill install --apply --yes
```

完整变更见 [v0.2.5...v0.2.6](https://github.com/liguangsheng/wildtoken/compare/v0.2.5...v0.2.6)。
